# 本地网页下载（当前支持新片场）

本 fork 增加了一个只使用 Python 自带功能的本地网页和下载服务，并修复了原解析器访问作品网页时返回 403 的问题。网页当前只支持新片场作品，原项目其他平台客户端保留，后续可继续接入。

## Windows 双击使用

1. 安装 Python 3.10 或更新版本，安装时勾选 **Add python.exe to PATH**。电脑已经有 Python 就不用重复安装。
2. 双击项目目录中的 **下载新片场.cmd**，自动启动服务并打开下载网页。
3. 在网页粘贴新片场作品链接，点击 **开始下载**，查看下载进度和结果。

例如：`https://www.xinpianchang.com/a13019115`。链接包含搜索参数也可以，也支持包含链接的分享文字。可以连续添加不同作品，任务按顺序下载；刷新页面可继续查看，服务重启后任务记录清空，已下载文件保留。

视频保存在项目目录的 `videodl_outputs/XinpianchangVideoClient/`。重名文件会自动加序号，不会覆盖已有视频。

下载完成后，文件已保存在上面的目录，也可以点击网页的 **另存视频** 通过浏览器保存副本。

使用时保持服务窗口打开，按 `Ctrl+C` 停止接收任务，当前下载完成后退出。不需要激活或退出虚拟环境，也不需要运行 pip、Node.js 或前端构建。

## 一条命令启动服务

```powershell
python web_server.py
```

浏览器访问 <http://127.0.0.1:8765/>。前后端使用同一个服务，无需分别启动。

只启动后端、不自动打开浏览器，或自定义端口和保存目录：

```powershell
python web_server.py --no-browser --port 8766 -o "D:\视频"
```

服务仅监听本机。如果提示端口占用，先打开已有服务的网页，或用 `--port` 更换端口。

## 直接使用命令行下载（可选）

```powershell
python xinpianchang.py "https://www.xinpianchang.com/a13019115"
```

自定义保存目录：

```powershell
python xinpianchang.py "https://www.xinpianchang.com/a13019115" -o "D:\视频"
```

使用本地源码，每次修改后直接生效，无需重新安装项目。

## 画质与 FFmpeg

自动选择网站当前提供的最高可用 MP4 画质。网站没有提供地址的清晰度不会被选用。

普通 MP4 直接下载，不需要 FFmpeg。只有网站提供 HLS/DASH 流时才需要 FFmpeg；可将 `ffmpeg.exe` 放在项目根目录，或将 FFmpeg 的 `bin` 目录加入 PATH。

这个入口支持 `www.xinpianchang.com/a数字` 形式的作品链接；素材库 `stock.xinpianchang.com` 仍使用原项目客户端。此入口没有登录功能，需要登录后才能播放的作品可能无法下载。

## fork 与上游更新

可以在自己的 fork 中提交这些改动。原项目的许可证和署名保留不变，继续适用其非商业许可证。

使用 `git remote -v` 检查仓库地址：`origin` 应指向你自己的 fork，原作者仓库通常命名为 `upstream`。同步上游前先提交本地改动；如果同一文件有修改，需要解决合并冲突。
